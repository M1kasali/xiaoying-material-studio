## 分阶段交付

1. 设计和工程骨架：本文、architecture.md、api.md、模板链路、基础 CI。
2. 后端闭环：会话、上传、任务服务、线程池、三个步骤、查询、失败控制。
3. 前端闭环：上传位、任务提交、任务状态跟踪、历史和账户切换。
4. 测试和交付：核心行为自动化测试、端到端手动验证、容器验收、README 补齐、GitHub 提交。

每一阶段完成时更新状态和实际验证记录；最终验收不接受未标明的占位行为。
