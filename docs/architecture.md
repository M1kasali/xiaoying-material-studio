# 架构与数据设计

## 当前范围

已实现工程骨架、数据库迁移、模板 API、会话、上传、三阶段后台任务及历史/结果查询，以及前端制作、历史、账户切换和刷新恢复。实际验证结果单独记录。

## 调用链

浏览器 → Next.js 页面及同源接口中间层 → Java API → MyBatis → MySQL。

Next.js 不承担业务执行和持久化。浏览器不需要知道 Docker 内部域名。Java 不配置宽泛 CORS；部署使用同源中间层。

## 数据表

唯一可执行的建表与种子来源：`backend/src/main/resources/db/migration/`。Flyway 随 Java 启动执行，第二次启动不会重复插入种子。SQL 使用 MySQL 8.4；数据库与 JDBC 会话按 UTC 存储时间，API 返回 ISO 8601 UTC，浏览器本地化展示。

| 表 | 职责 | 重要约束 |
| --- | --- | --- |
| app_user | 个人记录所属用户 | UUID 主键 |
| user_session | 服务器会话 | 仅保存随机令牌的 SHA-256 摘要与过期时间 |
| template | 模板及上传要求 | 1～4 张图片；全局支持 JPEG/PNG |
| upload_asset | 已上传素材 | 用户、唯一存储键、媒体类型、大小 |
| production_task | 任务聚合状态 | 所属用户、模板、阶段、结果、失败原因、时间、模拟参数快照 |
| task_asset | 任务引用的素材及顺序 | 每个任务的槽位唯一、素材不可重复 |
| task_step | 每一步的执行边界 | 任务+阶段唯一；开始/结束时间与错误 |

模板目前 6 个、3 个分类，素材要求覆盖 1/2/3 张图片。封面是项目原创 SVG，仅用于可信内置素材；用户上传仅接收经过内容检查的 JPEG/PNG。

## 后端任务状态

`QUEUED → RUNNING → SUCCEEDED / FAILED`，终态不可回退。

阶段：`VALIDATE → GENERATE → FINALIZE`。排队时阶段为空；处理中对应当前步骤；失败保留失败步骤；成功保留 FINALIZE。

1. 同步校验身份、模板、素材数量及归属；创建任务和关联记录，事务提交后派发。
2. 有界线程池顺序执行每个任务的三个步骤。每次开始/完成均用短事务写入 task_step 和任务状态；模拟等待不占用数据库事务。
3. 工作线程捕获异常，将任务置为 FAILED，停止后续步骤；结果整理成功后才写入可访问结果地址。
4. 线程池拒绝任务时将已创建记录标记为失败，避免永久等待。数据库短暂不可用导致的写入异常需记录日志及已知限制。
5. 查询接口只读数据库。异步执行不依赖页面打开和轮询请求。
6. 模拟延迟与指定失败阶段在创建时保存快照，避免运行中全局配置变化影响已提交任务。

启动时先把历史 QUEUED/RUNNING 任务及 RUNNING 步骤标记为失败，原因明确写为服务重启中止，再允许受理新任务。成功和失败终态不变。优雅停止时尝试中断工作线程并记失败；若进程强制退出，由下次启动补记。此方案不是断点续跑，只适用于单个 Java 实例。自动重试、分布式队列和受理幂等未实现。

## 身份与素材

本地演示提供 alice（小拾）和 bob（小光）。Java 生成 256 位随机会话令牌，数据库存 SHA-256 摘要和 24 小时过期时间；使用 HttpOnly、SameSite=Lax cookie，HTTPS 时通过 SECURE_COOKIE 启用 Secure。切换账户撤销当前旧令牌，退出时撤销会话并清 cookie。演示登录仅在 DEMO_ENABLED=true 时启用，不构成生产认证方案。浏览器写接口校验 Origin/Sec-Fetch-Site；无 Origin 的 CLI 请求允许访问。所有个人记录、素材和结果查询在 Java 校验用户归属，不接受客户端指定 userId。

上传文件以 UUID 存储键保存，原始文件名仅作显示并移除路径；检查大小（5 MB）、声明 MIME 与实际 JPEG/PNG 内容一致、可解码、总像素不超过 2000 万且单边不超过 10000。提交任务时检查模板数量、无重复素材、素材归属与大小/类型。文件写入后若数据库写入失败会清理文件。用户上传不接受 SVG；内置 SVG 封面是可信公开资源。素材与结果通过归属鉴权接口读取，响应不缓存并设置 nosniff，不公开本地目录。

模拟生成器选择第一个素材；FINALIZE 将其复制到独立结果路径后，才把结果地址和 SUCCEEDED 一起提交。若失败状态已确认落库则清理未完成结果；若数据库提交回执丢失，保留文件避免误删可能已经成功的结果，孤立文件清理留作已知限制。

## 前端状态

分别管理上传状态、提交请求状态、服务端任务状态和查询错误。每个 TaskCard 以 taskId 为 key 独立管理数据、请求、错误和定时器；每次响应后才安排下一次请求，避免同一轮询重叠。查询失败只更新请求错误，按 3/6/12 秒退避，也可手动重试。成功查询间隔 1.5 秒，终态停止。刷新详情或历史页会重新查询服务端历史；单任务链接也可恢复跟踪。

账户切换先移除当前用户，再按新的 userId 重新挂载私有页面部分。清理函数中止上传、提交、列表和轮询请求，释放对象 URL、移除计时器；响应落入组件前检查 signal.aborted。跨标签页通过 BroadcastChannel 和窗口重新聚焦时的 /api/me 校验同步身份。mergeTask 额外拒绝不同 ID、较旧时间戳和终态回退，防止状态串扰。

上传位独立管理 empty/uploading/ready/error 状态；只有所有上传位成功才可提交。提交使用同步 ref 和禁用按钮双重防重复。请求受理后立即恢复按钮，服务端继续执行。提交响应丢失不自动重发，提示先查历史。客户端草稿和未绑定任务的孤立素材不自动恢复或清理。

## 视觉约定

参考题目深色工作台：模板列表为分类导航+卡片网格；制作页为左侧模板/上传、右侧历史，小屏上下堆叠；另有完整历史页和单任务链接。

- 色板：背景 #101214、面板 #1A1D20、边线 #303438、正文 #F4F2EC、次要文字 #A4A9AB、强调 #D4E892。
- 字体：正文 Segoe UI / Microsoft YaHei；标志少量使用楷体；数字使用等宽数字特性。系统字体无需联网。
- 特征：原创插画封面像一组旅行和日常照片册；上传数量直接叠在封面上。沿用题图深色方向，将重点放在素材内容。
- 布局：桌面四列、平板三列、小屏两列；可见键盘焦点，减少动态效果偏好生效。

版本兼容参考：[Spring Boot 3.5](https://docs.spring.io/spring-boot/3.5/system-requirements.html)、[MyBatis Starter](https://mybatis.org/spring-boot-starter/mybatis-spring-boot-autoconfigure/)、[Next.js 安装](https://nextjs.org/docs/app/getting-started/installation)。具体锁定版本以项目清单为准。

开发依赖说明：ESLint 暂用 9.39.5，与当前 Next.js 配置依赖的 React/import/a11y 插件 peer 范围匹配；尝试 10.14.0 后发现 peer 冲突，故未保留。包仓库已将 ESLint 9 标记为不再支持；它仅参与本地/CI 静态检查，后续插件支持 ESLint 10 后一并升级。当前 `pnpm peers check` 无冲突。
